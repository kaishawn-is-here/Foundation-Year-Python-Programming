# Event Management System

This Python program is designed for managing events, such as conferences, workshops, or parties. Users should be able to perform the following tasks:
a.	Add an event, providing details such as name, date, time, location, and description.
b.	Update event details, allowing users to select specific fields (name, date, time, location, or description) to modify.
c.	Delete an event.
d.	Register attendees for an event and manage attendees by adding, updating, or deleting attendee information.
e.	Print the event schedule, including details of each event and the registered attendees.
