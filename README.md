# Event Management System

A Python program for managing events such as conferences, workshops, or parties.

## Features

- Add an event with its name, date, time, location, and description
- Update event details by choosing which field to change (name, date, time, location, or description)
- Delete an event
- Register attendees for an event, and add, update, or delete attendee information
- Print the event schedule, including each event's details and its registered attendees
